Nurse Deflowerer

Go hog wild — find those nurses!

Move: Arrow keys or WASD.
Goal: Catch every nurse on the ward to advance to the next level.
Portals: Walk off any edge to tunnel out the opposite side.
Danger: Security guards join the patrol starting level 2, one more each level after. They send you back to bed if they catch you — you've got 3 lives.
